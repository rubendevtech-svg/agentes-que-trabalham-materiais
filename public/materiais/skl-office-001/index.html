Antes de começar

O que ter em mãos.

A skill entra sozinha quando o pedido combina. O que muda o resultado é o arquivo de origem e o formato que você pede.

  • Uma conta do Claude. A central de ajuda lista skills e criação de arquivos nos planos Free, Pro, Max, Ultra, Team e Enterprise
  • A opção Code execution and file creation ligada (na tela nova de configurações ela se chama Create and edit files)
  • O arquivo de origem: o PDF da tabela, o documento do Word ou os dados do relatório
  • Arquivos de até 30 MB
  • Uma ideia clara do formato: quais colunas, quantos slides, quais seções

Fica de fora

Não mande

  • Planilhas com CPF, salário ou dados de cliente que não precisam ir
  • Senhas e dados bancários
  • Arquivos de origem desconhecida: um arquivo pode trazer instrução escondida para o Claude
  • Pedido de "só o texto" quando você quer o arquivo

O que as skills fazem

  • Excel: monta planilha .xlsx, por exemplo com os dados tirados de um PDF
  • PowerPoint: transforma um documento do Word em apresentação .pptx
  • Word: entrega o relatório em documento .docx
  • O arquivo sai na conversa, pronto para baixar
  • O Claude usa a skill sozinho quando o pedido combina; você não precisa chamar

O que elas não fazem

  • Não confere os números por você
  • Não garante que a formatação saia igual à da sua empresa
  • Não trabalha com arquivo acima de 30 MB
  • Não funciona com a opção de criar arquivos desligada

Copie, preencha e confira.

Pedidos de exemplo escritos pelo escritório. Dois partem dos exemplos da central de ajuda (PDF para planilha e Word para apresentação). Não foram testados por nós. Troque o que está entre colchetes pelos seus dados. Também em arquivo de texto editável.

Passo a passo

Como usar

  1. 01

    No Claude, vá em Settings > Capabilities e veja se Code execution and file creation está ligado. Na tela nova de configurações, o nome é Create and edit files. Os nomes podem aparecer traduzidos.

  2. 02

    Em Customize > Skills, confira se as skills de Excel, Word, PowerPoint e PDF estão ligadas.

  3. 03

    No plano Team, a opção vem ligada para a empresa. No Enterprise, o responsável pela conta confirma Code execution and file creation e Skills na aba Policy.

  4. 04

    Numa conversa nova, anexe o arquivo de origem e cole um dos pedidos, trocando o que está entre colchetes. Peça o arquivo, não o texto.

  5. 05

    Baixe o arquivo direto da conversa.

  6. 06

    Abra o arquivo e confira os números com a fonte antes de mandar para alguém.

Limite. Criar arquivos gasta mais do seu limite de uso que uma conversa normal. Arquivo de fora pode trazer instrução escondida: acompanhe o que o Claude faz.

Antes de usar

Checklist final

As marcações ficam só nesta tela e somem ao recarregar.

Abra o arquivo antes de mandar. O Claude pode errar um número ou uma linha. Confira com a fonte, ajuste e só depois envie.
