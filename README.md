# Agentes que Trabalham — Biblioteca gratuita

Publicacao estatica de materiais educativos gratuitos, preparada para Vercel. O repositorio contem somente o bundle publico, sem fontes de PDF, testes, historicos ou arquivos pagos.

Importar na Vercel: Framework Other; Root Directory raiz; Output Directory public; sem build e sem instalacao de dependencias. A configuracao esta em vercel.json.

Creditos e origem em public/LICENCAS.md e nas paginas dos materiais. Fontes de trabalho ficam no projeto local AGENTES-MATERIAIS.
